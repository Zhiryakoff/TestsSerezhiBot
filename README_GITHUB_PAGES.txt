# Военные сокращения — GitHub Pages

Это готовая статическая версия для GitHub Pages.

Загрузите ВСЕ файлы из этой папки в корень репозитория GitHub, чтобы `index.html`
лежал непосредственно в корне репозитория.

Файлы:
- index.html
- app.js
- data.js
- style.css
- manifest.json
- sw.js
- telegram.js
- .nojekyll

Python-бот в этот архив НЕ входит: GitHub Pages размещает статические файлы,
а Python на GitHub Pages не запускается.

После загрузки:
Settings → Pages → Build and deployment → Source: Deploy from a branch
→ Branch: main → Folder: /(root) → Save.
