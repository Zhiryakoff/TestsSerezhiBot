ВОЕННЫЕ ТЕСТЫ — GITHUB PAGES

1. Распакуйте этот архив.
2. Загрузите ВСЕ файлы и папки из распакованного архива в корень репозитория GitHub.
   Файл index.html должен находиться прямо в корне репозитория.
3. В Settings → Pages выберите Deploy from a branch → main → /(root) → Save.
4. Подождите публикацию GitHub Pages.

В приложении два главных раздела:
• Тест по Сокращениям — прежние тесты и экзамен.
• Тест по картинкам — 168 картинок, 3 части по 56 и экзамен.

Картинки и соответствующие им расшифровки хранятся отдельно и связываются по номеру:
1.jpg → 1-1.jpg, 2.jpg → 2-1.jpg и т. д.

Проверка ответа по тексту НЕ выполняется. После ввода пользователь нажимает «Показать ответ», сравнивает свой ответ с расшифровкой на картинке и сам нажимает «Верно» или «Неверно».

Важно: в загруженных архивах файлы фактически имеют расширение .jpg, поэтому они оставлены в исходном формате. Ничего переименовывать не нужно.
